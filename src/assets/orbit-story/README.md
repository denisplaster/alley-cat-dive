# Orbit Trash story panel art

Drop generated panel images here as `chN-MM.jpg` (e.g. `ch1-01.jpg`).

See [`docs/orbit-shotlist.md`](../../../docs/orbit-shotlist.md) for the full shot list,
naming scheme, art style guide, and how to wire each finished image into
`src/lib/orbit/data.ts`.

Until a panel's real art lands, it falls back to a placeholder (one of the three existing
orbit images), so the edition stays fully playable.
